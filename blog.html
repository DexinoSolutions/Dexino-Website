Microsoft 365 Security Checklist for Swiss SMEs

Microsoft 365 is often the centre of a small company’s communication, documents and collaboration. That makes the basic security configuration important.

Start with identity

Enable multi-factor authentication for all users, especially administrator accounts. Review inactive users and remove accounts that are no longer needed.

Protect email

Use strong spam and phishing protection, review forwarding rules and make sure employees know how to report suspicious messages.

Control access

Keep administrator roles limited. Users should only have the permissions they need for their work.

Document the setup

A simple document listing users, groups, mailboxes, shared mailboxes and security settings can save many hours during troubleshooting or audits.
